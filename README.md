# KCH Health Kiosk — Interactive Prototype

A lightweight static web prototype for desktop/mobile. It contains a procedural 3D kiosk concept and a six-step guided usage demo.

## Demo workflow
1. Welcome / login
2. Height + weight
3. Blood pressure
4. Optical glucose
5. AI analysis
6. Results / QR / receipt

## Run locally
The page uses Three.js from cdnjs. Open `index.html` in a browser with internet access, or serve the folder with any simple static server.

## Deploy to Render
Create a Static Site and publish this folder. `render.yaml` is included.

## Deploy to Netlify
Drag the entire folder into Netlify Drop, or deploy the folder via Netlify. `netlify.toml` is included.

## Important
This is a presentation/UX prototype. It is not manufacturing CAD and does not represent a medically validated device.
